# @pi-spice/all

All [pi-spice](https://github.com/0x2E/pi-spice) extensions in one package. The
`extensions/` directory bundled here is a publish-time copy of the repo's
`extensions/`; see the repo README for the extension list and per-extension
details.

Install the whole spice rack:

```bash
pi install npm:@pi-spice/all
```
